                             AllBinary Platform Clojure

What is it?

This repository contains code generated by the AllBinary Platform for support in Clojure.  
This repo is used to allow developers to skip the Clojure code generation step.

What are some example games with this Clojure code?

https://allbinary.itch.io (The downloads with "-clojure" in the filename are Clojure only builds. Currently that only includes nothing. Also the Clojure builds are not available on Google Play or other stores.)
